# Global Technologies Development

Global technologies development, assistance, and creation software integrated with artificial intelligence tools.

This project aims to make all technologies accessible to the general public and to promote them so that they are known to as many people as possible.

## Development Setup

To get started with the development of the AI components, you'll need to set up a Python environment.

1.  **Create a virtual environment:**

    ```bash
    python -m venv venv
    source venv/bin/activate  # On Windows, use `venv\Scripts\activate`
    ```

2.  **Install the dependencies:**

    ```bash
    pip install -r requirements.txt
    ```

3.  **Run the proof-of-concept script:**

    ```bash
    python src/main.py
    ```
